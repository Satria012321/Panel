=====================================
DATABASE SCHEMA
=====================================

📊 users table
├── id (UUID, PRIMARY KEY)
├── username (VARCHAR 255, UNIQUE)
├── password_hash (VARCHAR 255)
├── role (VARCHAR 20) [owner | admin | reseller]
├── balance (BIGINT)
├── created_at (TIMESTAMP)
└── updated_at (TIMESTAMP)

📊 api_keys table
├── id (UUID, PRIMARY KEY)
├── user_id (UUID, FOREIGN KEY → users.id)
├── key_type (VARCHAR 20) [CODM|MLBB|HOK|FF|PUBG|VAL|GI|AOV]
├── api_key (VARCHAR 255, UNIQUE)
├── serial_number (VARCHAR 255, UNIQUE)
├── days_valid (INT)
├── is_active (BOOLEAN)
├── created_at (TIMESTAMP)
├── expires_at (TIMESTAMP)
└── revoked_at (TIMESTAMP)

📊 invitations table
├── id (UUID, PRIMARY KEY)
├── created_by (UUID, FOREIGN KEY → users.id)
├── code (VARCHAR 255, UNIQUE)
├── role (VARCHAR 20) [owner|admin|reseller]
├── is_used (BOOLEAN)
├── used_by (UUID, FOREIGN KEY → users.id)
├── used_at (TIMESTAMP)
├── created_at (TIMESTAMP)
└── expires_at (TIMESTAMP)

📊 transactions table
├── id (UUID, PRIMARY KEY)
├── from_user_id (UUID, FOREIGN KEY → users.id)
├── to_user_id (UUID, FOREIGN KEY → users.id)
├── amount (BIGINT)
├── transaction_type (VARCHAR 50)
├── description (TEXT)
└── created_at (TIMESTAMP)

API ENDPOINTS SUMMARY
=====================================

🔐 Authentication
POST /api/auth/login - User login
POST /api/auth/register - User registration

🔑 Key Management (Main)
POST /api/connect - Validate/generate/revoke/check keys

👥 User Management
GET /admin/users - List all users (Owner/Admin)

💰 Balance Management
POST /admin/balance - Manage balances (Owner/Admin)

🎭 Role Management
POST /admin/role - Change roles (Owner only)

📨 Invitations
POST /admin/invitations - Manage invitations (Owner/Admin)

=====================================
USER ROLES & PERMISSIONS
=====================================

Owner
├── Balance: Unlimited
├── Manage Users: ✓ All
├── Change Roles: ✓ Yes
├── Create Invites: ✓ All roles
└── View Transactions: ✓ All

Admin
├── Balance: Unlimited
├── Manage Users: ✓ (except Owner)
├── Change Roles: ✗ No
├── Create Invites: ✓ Reseller only
└── View Transactions: ✓ All

Reseller
├── Balance: Max 9,999,999,999,999,999
├── Manage Users: ✗ No
├── Change Roles: ✗ No
├── Create Invites: ✗ No
└── View Transactions: ✓ Own only
