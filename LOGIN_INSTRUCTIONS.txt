                    KEY GENERATOR SERVER - LOGIN INSTRUCTIONS
================================================================================

STEP 1: Start the Application
================================================================================

Open terminal and run:
    pnpm dev

Wait for message: "✓ Ready in X.Xs"
Then open: http://localhost:3000


STEP 2: Create Owner Account & Get Your Invitation Code
================================================================================

Open a NEW terminal tab and run:
    node scripts/create-owner.js

You'll see something like:

    ✅ Owner account created successfully!
    
    📋 Owner Login Credentials:
       Username: owner
       Password: owner123
    
    🎟️  Invitation Code for You (Reseller):
       Code: A1B2C3D4E5F6G7H8I9J0
       Role: Reseller
       Expires: 4/1/2027, 4:00:00 PM

SAVE the invitation code (the long alphanumeric string) - you'll need it next!


STEP 3: Register Your Account
================================================================================

Go back to: http://localhost:3000

1. Click the "Register" tab at the top
2. Fill in the form:
   - Username: Choose any username (e.g., "myreseller")
   - Password: Choose a secure password
   - Confirm Password: Repeat your password
   - Invitation Code: Paste the code from STEP 2
3. Click "Register"

You're now logged in as a Reseller!


STEP 4: Start Using the App
================================================================================

Now you can:

As a Reseller (your account):
  • Generate API keys for 8 games (CODM, MLBB, HOK, FF, PUBG, VAL, GI, AOV)
  • View your balance
  • See your transaction history
  • Use the API endpoints

To Login as Owner (optional - to manage users):
  1. Click "Login" tab
  2. Enter: username=owner, password=owner123
  3. Click "Login"
  
  As Owner you can:
  • View all users
  • Create invitations for new users
  • Manage user balances
  • Change user roles
  • View all transactions

TROUBLESHOOTING
================================================================================

Q: "Invitation code is invalid"
A: Make sure you:
   - Copied the code correctly from STEP 2
   - Used it before it expired (usually 30 days)
   - Haven't used it twice (each code works once only)

Q: "Username already exists"
A: Choose a different username in the registration form

Q: "Can't find the registration page"
A: Make sure you're on http://localhost:3000 and click the "Register" tab

Q: "Database connection failed"
A: Run this command in a terminal:
   node scripts/init-db.js

Q: "Command not found: pnpm"
A: Install Node.js dependencies first:
   pnpm install

IMPORTANT NOTES
================================================================================

• Each user gets a unique API key per game
• API keys are valid for 30 days by default
• Keys can be revoked anytime
• Balance is tracked for Resellers (max: 9,999,999,999,999,999)
• Owner and Admin have unlimited balance
• All actions are logged in the transactions table
